# ACT05_PullRequest_6contra1

Pràctica de Git i GitHub per a sis alumnes, per torns individuals. Durada: 60 minuts.

Cada alumne crearà una branca, proposarà una millora, obrirà una pull request perquè la revisi el docent, respondrà a un comentari i esperarà que el docent integri el canvi.

Llegiu l'[enunciat de l'activitat](ENUNCIAT.md). El docent ha d'afegir les sis persones com a col·laboradores abans de la sessió.
